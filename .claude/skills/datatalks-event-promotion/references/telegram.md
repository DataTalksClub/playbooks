# Telegram

Use this reference when drafting Telegram announcements for DataTalks.Club courses, modules, events, workshops, reminders, recaps, or operational lists.

Telegram posts should be direct, useful, and easy to scan in a chat feed. They can be longer than X posts, but they should stay more operational than LinkedIn posts. The reader should quickly understand what is happening, why it matters, and which link to open next.

## Core Style

Prefer:

- A plain opening that names the course, module, event, or week.
- Short paragraphs with one idea each.
- Concrete descriptions of what learners will study, build, evaluate, or see.
- Simple bullet lists for module topics, workshop agenda, materials, or takeaways.
- Labelled links on separate lines.
- Calm explanatory copy before the CTA.

Avoid:

- Hype openings such as "Exciting news" or "Don't miss this".
- Dense LinkedIn-style arguments with long setup.
- Hashtags.
- Inline link-heavy sentences.
- Overly polished sponsor language.
- Inventing homework, deadlines, materials, or outcomes that are not in the source.

## Structure

For module or course-week announcements, use this shape:

```markdown
We start Module [N] on [Module title].

[One short paragraph: what the learner can now do, and what this module adds.]

We cover:

- [Topic]
- [Topic]
- [Topic]

Materials:
[link]

Recording:
[link]

Companion article:
[link]

[Homework status in one or two sentences.]

Homework:
[link]

Submit:
[link]

Deadline: [Month D, YYYY at HH:MM CET/CEST] ([Month D at HH:MM UTC]).

Next week, [one-sentence preview of the next module].

Questions go in the course Slack channel:
[link]
```

Module announcement rules:

- Do not add a separate title line. The first sentence names the module.
- Keep the "why it matters" paragraph to two or three sentences, stated positively. Skip "Without X, every Y is a guess" contrasts.
- When homework is a draft, say it briefly: "Homework [N] is currently a draft and the questions will likely change. We will announce once it's ready." Do not explain placeholders or tell learners how to plan around them.
- Write the local deadline time with a short timezone label (CET in winter, CEST in summer), followed by UTC in brackets. Do not use `Europe/Madrid` in Telegram copy.
- No emojis, bold, or hashtags.

For event or workshop announcements, use this shape:

```markdown
[Relative timing or date], we are running [event/workshop name]:

[Event title]

[Who it is for, or the problem it helps with.]

[What participants will see, learn, build, or discuss.]

[Date]
[Time and timezone]
[Format or location]

RSVP:
[registration link]
```

For reminders, keep the same facts but make the copy shorter. Lead with the timing, then give one strong reason to attend. Do not repeat the full main announcement.

For educational Telegram posts, start with the idea, distinction, problem, or misconception. Teach the point first, then connect it to the event or module near the end.

## Link Formatting

Use labelled links on separate lines:

```markdown
Materials:
https://...

Course:
https://...

RSVP:
https://...
```

Do not hide essential links inside long paragraphs. If a source gives a repository, course homepage, playlist, registration page, Slack link, FAQ, or homework link, include only the links needed for the specific post.

## Requirements By Post Type

Module announcement:

- Name the course and module.
- Explain why the module matters in practical terms.
- List the main topics covered.
- Include materials and course links when available.
- Mention homework, deadlines, Slack, Telegram, playlist, or FAQ only when relevant and supplied.

Event announcement:

- Name the event or workshop.
- Include date, time, timezone, format, and registration link.
- Explain who should join and what they will learn or see.
- Use the speaker name only when supplied.

Reminder:

- Open with the timing, such as "This Monday" or "Tomorrow".
- Give one specific reason to attend.
- Include essential event details and the RSVP link.
- Keep it shorter than the main announcement.

Event series or operational list:

- Use numbered items.
- Put each event's title, subtitle if useful, date, time, and link on separate lines.
- End with the main course or campaign CTA if there is one.

Recap:

- Say what happened and what people can revisit.
- Include recording, notes, or materials links when available.
- Do not claim audience reactions or outcomes unless the source includes them.

## Tone Calibration

Telegram can be matter-of-fact and slightly more instructional than social posts. A good Telegram announcement often sounds like:

- "We start Module [N] on [module title]."
- "Once you have [previous capability], you need to [next capability]."
- "In this module, we [do the practical work]."
- "With [practice], you can [concrete outcome]."

The post should feel like a useful course or community update, not an advertisement.
