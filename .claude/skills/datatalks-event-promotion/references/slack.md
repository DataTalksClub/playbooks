# DataTalks.Club Slack

Use this reference for announcements, reminders, recaps, and engagement prompts posted in the DataTalks.Club Slack community.

Slack copy should feel like a useful message inside an active community. It can share the same facts and campaign angle as Telegram, but it should make use of conversation and threads when participation is useful.

## Core Style

Prefer:

- A direct opening with the date, timing, event, or community question.
- Short paragraphs and compact bullets.
- A clear explanation of who the event is for or what problem it addresses.
- Event details and the primary link on easy-to-find lines.
- A conversational CTA such as joining the event, sharing a question, or replying in thread.

Avoid:

- Copying a long LinkedIn post into Slack.
- Hashtags.
- Hype, corporate sponsor language, or artificial urgency.
- Using `@channel`, `@here`, or user mentions unless the user or source explicitly requests them.
- Inventing a channel name or assuming the message can be posted workspace-wide.

## Post Types

Main announcement:

- Name the event and explain the practical problem it addresses.
- Include a short list of what people will see, learn, or do when supported.
- End with date, time, timezone, format, and registration link.

Reminder:

- Lead with `Tomorrow`, `This Monday`, or the supplied timing.
- Keep it shorter than the main announcement.
- Repeat one strong reason to join, then the essential logistics and link.

Engagement prompt:

- Ask one specific question the community can answer quickly.
- Offer examples only to clarify the scope, not to steer every answer.
- Ask people to reply in thread when a thread will keep the channel readable.
- Keep event registration secondary unless the post's main purpose is promotion.

Recap:

- State what is available to revisit.
- Include the recording, notes, slides, or materials link supplied by the source.
- Optionally ask one concrete follow-up question for the thread.

## Delivery Check

- The message names or targets the intended Slack audience without assuming access to a specific channel.
- The CTA matches the post type: register, watch/read, or reply.
- Conversation prompts are genuine questions, not promotional statements with a question mark.
- Links and event facts match the source.
