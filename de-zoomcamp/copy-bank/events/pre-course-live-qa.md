## What We'll Cover

Alexey will walk through:

- What you'll learn: Docker, PostgreSQL, Terraform, Google Cloud, BigQuery, orchestration, dbt, Spark, streaming, and dashboards
- How the course works: videos, homework, deadlines, leaderboard, peer review, and certificate path
- What you'll build: an end-to-end data pipeline with ingestion, storage, warehouse modeling, transformations, and a dashboard
- How to handle the tricky parts: environment setup, cloud accounts, debugging pipelines, and keeping up with the schedule
- Where to get help: DataTalks.Club Slack, Telegram updates, FAQ, and community support

You'll also hear practical advice on how to pace the course and avoid getting stuck in setup or infrastructure details.

## Is This Course for You?

DE Zoomcamp is a free hands-on course for people who want to learn modern data engineering by building real pipelines. It covers the full path from local development to cloud warehouses, orchestration, transformations, batch processing, streaming, and project delivery.

You should be comfortable with command line basics, basic programming concepts, SQL fundamentals, and Git basics. You do not need previous data engineering experience, prior cloud experience, advanced Python, or a degree.
