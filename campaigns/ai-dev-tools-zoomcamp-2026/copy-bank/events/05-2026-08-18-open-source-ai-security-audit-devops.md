## About Event

This is the 5th workshop in our series to update the AI Dev Tools Zoomcamp content.

This workshop updates [Module 4: Open-Source AI Tools for Security, Audit, and DevOps](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/04-devops?utm_source=luma).

In this hands-on session, Alexey Grigorev will show how to use open-source AI tools around the production workflow, not only during coding.

You will see how AI can support pull request audit, security scanning, agent and MCP supply-chain checks, Kubernetes diagnostics, incident investigation, and AI tool governance.

The module is deliberately narrow: only open-source AI tools, and only security, audit, and DevOps.

## What You'll Learn

- Where the real risks sit in an AI-assisted project: generated code, agent tools, MCP servers, skills and plugins, CI/CD, operations, and model gateways
- How to use PR-Agent for AI-assisted pull request audit, and why an AI review is an audit assistant rather than an approval
- How to make a deterministic security scanner available to an AI assistant with the Semgrep MCP server
- How to plant a vulnerability, have an assistant find it with Semgrep, fix it, and verify the fix by re-running the scan
- How to audit an agent extension pack with Snyk Agent Scan: instructions, reusable workflows, subagents, hooks, and MCP servers
- Why agent extensions are a supply chain, and how to write a permission table for the tools you install
- How to use K8sGPT for AI-assisted Kubernetes diagnostics, and how to verify its answers with `kubectl`
- Where incident investigation tools such as HolmesGPT fit into an on-call workflow
- How to govern AI tool access with LiteLLM and Ollama: virtual keys, budget limits, model routing, audit logs, and redaction
- Why "open-source AI tool" doesn't automatically mean "private", and which model provider ends up seeing which data
- How to decide which actions require human approval

By the end, you'll know how to build a security, audit, and DevOps hardening package for your final project. It answers what you audited, which findings were real, what you fixed, and what remains risky.

Like the other workshops, this will be a live demo with practical tips and time for Q&A.
