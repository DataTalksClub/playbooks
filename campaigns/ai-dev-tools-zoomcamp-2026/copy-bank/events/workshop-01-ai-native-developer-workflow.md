## About Event

This is the 1st workshop in our series to update the AI Dev Tools Zoomcamp content.

This workshop updates [Module 1: AI-Native Developer Workflow](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/01-overview?utm_source=luma).

In this hands-on session, Alexey Grigorev will show how to turn AI coding tools into a disciplined developer workflow.

You will see how to move from a vague idea to a concrete plan, use AI assistants for exploration and implementation, review generated code, test it, and keep enough context to understand what changed.

## What You'll Learn

- What "AI-native developer workflow" means in practice
- How to compare chat assistants, terminal coding agents, agentic IDEs, cloud agents, and project bootstrappers
- When to use ChatGPT, Claude, Gemini, Claude Code, Codex, Gemini CLI, Cursor, Windsurf, Zed, Antigravity, Lovable, Bolt, Replit, and similar tools
- How to practice context engineering with `AGENTS.md`, `CLAUDE.md`, repository instructions, product specs, architecture notes, testing guidelines, and security checklists
- How to break a task into spec, context, plan, edit, run, test, inspect diff, review, and commit
- How to use AI to understand an unfamiliar codebase
- How to ask AI for code without outsourcing your engineering judgment
- How to review generated code before accepting it
- How to use tests as a guardrail for AI-assisted development
- How to avoid tool-hopping during the cohort
- How to decide when to ask AI, when to inspect manually, and when to simplify the task

By the end, you'll have a practical workflow for using AI developer tools in a way that helps you move faster while still understanding and maintaining the code.

Like the other workshops, this will be a live demo with practical tips and time for Q&A.
