## About Event

This is the 5th workshop in our series to update the AI Dev Tools Zoomcamp content.

This workshop updates [Module 5: Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/05-agent-capabilities?utm_source=luma).

In this hands-on session, Bhavani Ravi will show how modern coding agents are extended and customized.

You will see how agents use project instructions, MCP, reusable workflows, skills, commands, hooks, specialized subagents, plugins, extensions, and custom agent patterns.

## What You'll Learn

- How modern coding agents are extended and customized
- How to think about Claude Code, Codex, OpenCode, Cursor, GitHub Copilot, Aider, and similar tools as part of the same broader agent workflow
- How project instructions guide an agent inside a repository
- How MCP connects assistants to tools, context, and actions
- How reusable workflows, skills, and commands make common tasks repeatable
- How specialized subagents can handle focused work
- How hooks can add checks or automation around agent actions
- How plugins and extensions package agent capabilities
- How custom agents fit into the broader workflow
- How to design an agent extension pack for your own app
- How to think about permissions, local files, remote services, and security
- How to review agent output with tests, diffs, and human judgment

By the end, you'll understand how to extend a coding agent around your app with project instructions, a reusable workflow, a specialized subagent, a hook, an MCP tool or server, and either a small plugin/extension package or a custom agent.

Like the other workshops, this will be a live demo with practical tips and time for Q&A.
