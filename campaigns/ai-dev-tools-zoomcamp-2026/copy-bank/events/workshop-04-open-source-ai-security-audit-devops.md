## About Event

This is the 4th workshop in our series to update the AI Dev Tools Zoomcamp content.

This workshop updates [Module 4: Open-Source AI Tools for Security, Audit, and DevOps](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/04-ai-security-audit-devops?utm_source=luma).

In this hands-on session, Alexey Grigorev will show how to use open-source AI tools around security, audit, and DevOps workflows.

You will see how AI can support PR audit, security scanning, agent/MCP/skill security checks, Kubernetes diagnostics, incident investigation, and AI tool governance.

## What You'll Learn

- Why AI-assisted projects need security, audit, and DevOps hardening
- How to use AI around pull request audit
- How PR-Agent fits into the review workflow
- How to make security scanning accessible to AI tools
- How Semgrep MCP can support secure code review
- How Snyk Agent Scan fits agent, MCP, and skill security checks
- How K8sGPT can help with Kubernetes diagnostics
- How LiteLLM and Ollama fit into AI tool governance and local workflows
- Where optional tools such as HolmesGPT and Stakpak may fit
- How to investigate incidents with AI support
- How to package hardening work for the final project
- How to keep humans, policy, and audit trails in the loop

By the end, you'll understand how to create a security, audit, and DevOps hardening package for your final project.

Like the other workshops, this will be a live demo with practical tips and time for Q&A.
