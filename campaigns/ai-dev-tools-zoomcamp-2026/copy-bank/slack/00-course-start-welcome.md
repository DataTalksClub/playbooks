For this course, the important habit is:

Use AI tools, but still read the code, run it, debug it, test it, and document what you did.

If you get stuck, please ask here. The most useful question format is:

- What are you trying to do?
- Which module or homework is it from?
- What command did you run?
- What error did you get?
- What did you already try?
- Link to your repo or paste a small relevant snippet.

Please use threads for specific debugging questions. It keeps the channel readable and makes answers easier to find later.
