Slack is the support and discussion layer for AI Dev Tools Zoomcamp.

- Nudging learners to ask questions in threads.
- Normalizing common blockers.
- Pointing people to the right docs.
- Encouraging progress updates.
- Helping moderators keep conversations organized.
- Turning quiet weeks into practical discussion.

## Recommended Cadence

Course start:

- Pin or post `00-course-start-welcome.md`.
- Post one first-week question prompt from `01-first-week-nudges.md`.

Each module week:

- Let the Telegram module announcement land first.
- Add one Slack-specific prompt from `03-weekly-module-prompts.md`.
- If questions are quiet, post one blocker prompt 24-48 hours later.

Homework weeks:

- Use `02-homework-and-deadline-support.md` for start, mid-week, and deadline nudges.
- Ask learners to share errors, screenshots, logs, and repo links in threads.

Project phase:

- Use `04-final-project-and-peer-review-nudges.md`.
- Focus on scope, reproducibility, deployment, documentation, and peer review.

Any week:

- Use `05-moderator-replies-and-faq-snippets.md` to answer repeated questions quickly.

## Slack Style

- Keep messages short enough to read inside the channel.
- Prefer one clear ask per message.
- Ask learners to reply in threads when the topic is specific.
- Ask for error messages, commands, screenshots, repo links, and what they already tried.
- Avoid answering debugging questions with guesses. Ask for the smallest reproducible context.
- Keep the tone practical and supportive.
