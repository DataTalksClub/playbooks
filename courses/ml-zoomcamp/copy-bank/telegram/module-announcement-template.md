# Telegram Module Announcement Assembly Guide

The 2026 Telegram announcements in this folder are fully resolved and ready for editorial review. This file is a guide, not publishable copy.

Follow `skills/datatalks-event-promotion/references/telegram.md` and the AI Dev Tools Zoomcamp announcements in `courses/ai-dev-tools-zoomcamp/copy-bank/telegram/`.

For a future cohort, create each announcement from `courses/ml-zoomcamp/course.yaml`, the campaign `course.yaml`, and the cohort folder in the course repository (`cohorts/<year>/README.md` and `cohorts/<year>/homework/`). Include:

- An opening sentence in the form "We start Module N on [Module title]." No separate title line.
- A short paragraph that connects the module to the learner's current stage and says why it matters.
- A "We cover:" bullet list of the module topics.
- A note when a module's original videos are outdated and learners should use the workshop instead (Modules 5, 9, and 10 in 2026), with the workshop link.
- The module materials link.
- One sentence on what the homework asks, then the homework and submission links and the deadline. Label homework as a draft only when the repository marks it so.
- Deadlines with a short local timezone label followed by UTC in brackets. Homework is due Mondays at 23:00 UTC, which is Tuesday 01:00 CEST until the clocks change in late October and Tuesday 00:00 CET after that.
- A one-sentence preview of the next module or project.
- The course Slack channel for questions.

Module 7 is the midterm project, and there is no Homework 7. Midterm and capstone posts replace the homework block with the project requirements, the submission and peer-review deadlines, the peer-review rule, and the certificate rule.

Keep paragraphs short. No emojis or bold. Use a practical, community-oriented DataTalks.Club voice.

Submission links follow the pattern `https://courses.datatalks.club/ml-zoomcamp-<year>/homework/hwNN` and `.../project/<midterm|capstone1|capstone2>`.
