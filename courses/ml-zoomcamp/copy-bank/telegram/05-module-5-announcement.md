We start Module 5 on Deploying Machine Learning Models.

A model in a notebook is only useful to you. In this module, we turn a trained model into a web service that other applications can call.

We cover:

- Saving and loading trained models
- Moving from a notebook to scripts
- Serving predictions with FastAPI and Pydantic
- Managing the environment with uv
- Packaging the service with Docker
- Deploying to the cloud

Parts of the original module are outdated. Watch the theory videos, then use the FastAPI and uv workshop for the current setup.
