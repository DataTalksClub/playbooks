We start the midterm project.

For the next two weeks, you apply everything from Modules 1 to 6 to a problem of your choice. You pick a dataset, train and evaluate a model, and deploy it as a web service.

The project should include:

- A problem description and how the model will be used
- Data preparation and EDA with feature importance analysis
- Several trained and tuned models, and the one you selected
- A training script and a prediction service exported from the notebook
- Dependency and environment files, and a Dockerfile
- A deployed model, or a video or screenshot of the running service

Use a new public dataset. Datasets from the lectures and homework don't count.
