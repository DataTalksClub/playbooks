We start Module 9 on Serverless Deep Learning.

Once you have a deep learning model, you need a way to serve it without running a server all the time. In this module, we deploy models with AWS Lambda.

We cover:

- How serverless deployment works
- Deploying models with AWS Lambda
- Running models with ONNX Runtime
- Exposing Lambda functions through API Gateway

Use the workshop for most of this module. In the original module, units 9.1, 9.2, and 9.7 are still useful, and units 9.3 to 9.6 are outdated.
