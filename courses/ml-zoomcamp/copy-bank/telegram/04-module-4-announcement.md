We start Module 4 on Evaluation Metrics for Classification.

Once you have a classification model, you need to know how good it really is. Accuracy alone can be misleading, especially when classes are imbalanced. With the right metrics, you can compare models and report performance you can trust.

We cover:

- Accuracy, precision, recall, and F1 score
- Confusion matrices
- ROC curves and AUC
- Cross-validation
- Comparing against a dummy baseline
