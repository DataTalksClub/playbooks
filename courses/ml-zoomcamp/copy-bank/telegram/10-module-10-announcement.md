We start Module 10 on Kubernetes and TensorFlow Serving.

When a model needs to handle more traffic, you need a way to run and scale it reliably. In this module, we serve models with TensorFlow Serving and deploy them to Kubernetes.

We cover:

- Core Kubernetes concepts for model deployment
- Serving models with TensorFlow Serving
- A separate pre-processing service
- Local testing with Docker Compose
- Scaling and load balancing
- Deploying to EKS

Parts of the original module are outdated, so use the workshop. Lessons 10.5 and 10.8 are still useful.
