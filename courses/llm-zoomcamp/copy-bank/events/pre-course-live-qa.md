## What We'll Cover

Alexey will walk through:

- What you'll learn: RAG, agentic workflows, vector search, orchestration, evaluation, monitoring, and production-style LLM apps
- How the course works: videos, homework, deadlines, leaderboard, peer review, and certificate path
- What you'll build: an end-to-end RAG or agent application with retrieval, evaluation, interface, monitoring, and clear docs
- How to make practical choices: hosted APIs vs local models, managing costs, choosing tools, and evaluating answers
- Where to get help: DataTalks.Club Slack, Telegram updates, FAQ, and community support

You'll also hear practical advice on how to learn without getting lost in the fast-moving LLM tool landscape.

## Is This Course for You?

LLM Zoomcamp is a free hands-on course for programmers who want to build useful LLM applications, not train models from scratch. It focuses on application engineering: retrieval, tools, agents, evaluation, feedback, monitoring, and documentation.

You should be comfortable writing code, reading code, using Git, using the command line, and running Docker. You do not need previous ML or AI experience, a GPU, a paid cloud account, advanced math, or a degree.
