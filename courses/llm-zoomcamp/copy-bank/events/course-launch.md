Alexey will walk through:

- The first week: how to think about LLM providers, API keys, local models, costs, and the first RAG workflow

- The course map: agentic RAG, vector search, orchestration, evaluation, monitoring, and optional advanced techniques

There will also be time for live questions, so bring anything about RAG, agents, vector databases, LLM providers, evaluation, or project ideas.

## Starting LLM Zoomcamp?

LLM Zoomcamp is a free hands-on course for programmers who want to build useful LLM applications, not train models from scratch. It focuses on application engineering: retrieval, tools, agents, evaluation, feedback, monitoring, and documentation.

You should be comfortable writing code, reading code, using Git, using the command line, and running Docker. You do not need previous ML or AI experience, a GPU, a paid cloud account, advanced math, or a degree.
