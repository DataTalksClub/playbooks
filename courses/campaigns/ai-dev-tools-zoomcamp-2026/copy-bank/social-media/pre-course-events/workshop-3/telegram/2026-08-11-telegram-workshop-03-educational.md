# Post

MCP, skills, hooks, subagents, and plugins are not interchangeable names for the same thing.

They solve different problems:

- Project instructions tell the agent how to work inside a repository
- MCP gives it external context, tools, or actions
- Skills and commands make a repeated procedure reusable
- Subagents separate focused work and context
- Hooks run checks or automation around an action
- Plugins and extensions package capabilities that belong together

Starting from the problem makes the choice easier. If the agent lacks a repository rule, adding MCP will not fix it. If it needs to call an external service, another instruction file is not enough.
