# Post

On August 17, we are running Workshop 3 of AI Dev Tools Zoomcamp 2026:

Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents

Modern coding agents can be extended in many ways. You can give them repository instructions, connect external tools through MCP, package repeated procedures as skills, delegate work to subagents, run hooks around actions, or install plugins.

The useful question is not how many extensions an agent supports. It is which capability your workflow actually needs.

Alexey will organize these mechanisms around practical problems and build an extension pack around an application. He will show how to add context, tools, reusable procedures, specialist roles, and automatic checks while keeping permissions, security, tests, diffs, and human review in place.

Join if you use coding agents and want to adapt them to your own repositories and workflows.
