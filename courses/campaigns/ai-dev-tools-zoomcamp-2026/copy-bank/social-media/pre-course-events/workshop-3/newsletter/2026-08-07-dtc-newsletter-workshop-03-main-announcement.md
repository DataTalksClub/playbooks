## Free workshop: Coding Agent Capabilities

Join us on August 17 for Workshop 3 of AI Dev Tools Zoomcamp 2026:

Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents

Modern coding agents can be extended in many ways. Project instructions give them repository context. MCP connects them to external tools and information. Skills and commands make procedures reusable. Subagents handle focused work. Hooks add automatic checks. Plugins and custom agents package several capabilities together.

Knowing the names is only the beginning. Developers also need to decide which mechanism fits a particular workflow, what access it should receive, and how its output will be reviewed.

Alexey Grigorev will build an extension pack around an application and explain these decisions as he works. Join to see how the capabilities fit together and how permissions, security, tests, diffs, and human judgment remain part of the workflow.
