On August 17, we are running Workshop 3 of AI Dev Tools Zoomcamp 2026:

Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents

This workshop is for developers who already use coding agents and want to adapt them to a real repository or team workflow.

Alexey will explain how to choose an extension based on what the agent is missing: repository context, an external tool, a reusable procedure, a specialist role, or an automatic check. He will then combine these mechanisms into an extension pack around an application.

Join to understand how MCP, skills, commands, hooks, subagents, plugins, and custom agents fit together, including the permissions, security, tests, diffs, and review needed when an agent gains more capability.
