# Thread

## Post 1

Before extending a coding agent, identify the missing capability. Adding another integration without a clear job usually creates more configuration, permissions, and failure modes.

## Post 2

If the agent is missing repository rules, add project instructions. If it needs external context or an action, use MCP. If the same procedure repeats, package it as a skill or command.

## Post 3

Use a subagent when focused work needs separate context. Use a hook when a check must run automatically around an action. Use a plugin or extension when several capabilities need to be installed and shared together.
