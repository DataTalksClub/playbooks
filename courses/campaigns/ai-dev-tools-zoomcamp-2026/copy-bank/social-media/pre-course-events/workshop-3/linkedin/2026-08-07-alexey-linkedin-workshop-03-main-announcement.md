# Post

On August 17, I am running the third free workshop for AI Dev Tools Zoomcamp 2026: Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents.

Coding agents can be extended with project instructions, MCP, skills, commands, hooks, subagents, plugins, and custom agents. The names vary between tools, and it is not always clear which mechanism solves which problem.

In the workshop, I will organize these capabilities around practical needs: giving an agent project context, connecting it to an external system, making a workflow reusable, delegating focused work, and adding automatic checks.

Join if you already use coding agents and want to adapt them to your own repositories and workflows. We will build an extension pack around an application and discuss permissions, review, and security. August 17, 2:00 PM GMT+2: https://luma.com/ap4l3qlj
