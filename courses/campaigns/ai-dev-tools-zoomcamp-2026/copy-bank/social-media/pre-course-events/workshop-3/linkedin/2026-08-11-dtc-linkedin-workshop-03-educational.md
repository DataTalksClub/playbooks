# Post

Different coding-agent problems need different extension mechanisms. Start by naming what the agent is missing.

Use project instructions for repository rules. Use MCP for external context, tools, or actions. Use a skill or command for a procedure that should run the same way more than once.

Use a subagent for focused work with separate context. Use a hook for checks that should run automatically. Use a plugin or extension to package capabilities that a team or project needs together.
