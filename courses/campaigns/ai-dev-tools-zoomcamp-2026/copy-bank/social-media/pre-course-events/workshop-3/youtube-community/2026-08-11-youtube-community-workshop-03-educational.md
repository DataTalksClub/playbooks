# Post

Before adding a new capability to a coding agent, ask what is missing:

- Repository knowledge: add project instructions
- External context or actions: use MCP
- A repeated procedure: create a skill or command
- Focused work with separate context: use a subagent
- A check that must run automatically: add a hook
- Several capabilities that belong together: package a plugin or extension

This keeps the design tied to a real workflow instead of collecting integrations without a clear job.
