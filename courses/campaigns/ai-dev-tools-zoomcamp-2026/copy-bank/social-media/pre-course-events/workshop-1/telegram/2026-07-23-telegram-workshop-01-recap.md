# Post

Coding agents can now write code faster than we can read it.

That changes the developer workflow. We need to be precise about what we want, give the agent the right project context, and check what comes back.

This was the focus of Workshop 1 of AI Dev Tools Zoomcamp 2026:

AI-Native Developer Workflow: Using AI Tools Without Losing Control

In the workshop, Alexey covers:

- Spec-driven development: turn an idea into a specification before writing code
- Context engineering: document the commands, constraints, and project rules an agent needs
- Loop engineering: run agents repeatedly over small tasks and check the results
- Graph engineering: organize the handoffs between product manager, engineer, and tester agents
