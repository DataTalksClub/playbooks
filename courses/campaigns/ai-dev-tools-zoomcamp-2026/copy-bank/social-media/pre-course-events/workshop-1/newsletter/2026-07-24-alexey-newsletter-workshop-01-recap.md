# Newsletter Section

## Coding agents now write code faster than I can read it

This changes the work I need to do before and after code generation.

Before an agent starts, I need to explain what I want and give it the right project context. After it finishes, I need to run the code, test it, inspect the changes, and check that it solved the right problem.

This was the focus of Workshop 1 of AI Dev Tools Zoomcamp 2026:

AI-Native Developer Workflow: Using AI Tools Without Losing Control

In the workshop, I organize the workflow into four areas:

- Spec-driven development: define the project and break it into clear tasks before writing code
- Context engineering: make commands, constraints, and project rules available to the agent
- Loop engineering: design how an agent picks up tasks, checks its work, and decides when to continue
- Graph engineering: structure the work and handoffs between specialized agents
