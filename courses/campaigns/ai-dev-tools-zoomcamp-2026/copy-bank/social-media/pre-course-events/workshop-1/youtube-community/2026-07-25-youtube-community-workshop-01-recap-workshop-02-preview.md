AI-Native Developer Workflow: Using AI Tools Without Losing Control

Three takeaways from the workshop:

1. Start with a specification. Write down what you want and break it into clear tasks before asking an agent to implement it.

2. Keep project context in the repository. Use AGENTS.md and supporting documents for commands, constraints, testing guidelines, and project rules.

3. Design the workflow around the agent. A loop controls repeated tasks and checks. A graph defines roles and handoffs across several agents.
