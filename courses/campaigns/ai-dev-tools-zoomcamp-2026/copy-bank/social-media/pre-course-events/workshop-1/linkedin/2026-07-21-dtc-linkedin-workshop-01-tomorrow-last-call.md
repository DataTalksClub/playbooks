Workshop 1:
AI-Native Developer Workflow: Using AI Tools Without Losing Control

Wednesday, July 22
9:00 AM - 10:30 AM GMT+2
YouTube

Alexey Grigorev will show how to turn AI coding tools into a disciplined developer workflow:

- Move from a vague idea to a concrete plan
- Use AI assistants for codebase exploration and implementation
- Add enough project context for useful output
- Run and test the code
- Inspect the diff before accepting changes
- Review generated code with your own engineering judgment

We will also compare where different tools fit: chat assistants, terminal coding agents, agentic IDEs, cloud agents, and project bootstrappers.
