# Post

2 opposite ways to use AI coding tools:

1. Avoid them because the output is hard to trust.
2. Accept too much generated code without enough review, tests, or understanding of what changed.

Both approaches miss the useful middle.

AI tools work better when they are part of a disciplined developer workflow:

- Write a short spec
- Add project context
- Ask for a plan
- Make a small change
- Run the code
- Test it
- Inspect the diff
- Review the result
- Commit only what you understand
