## Event Folders

- `event-series/`: Posts that announce or discuss the complete pre-course event series.
- `workshop-1/`: AI-Native Developer Workflow.
- `workshop-2/`: Build and Ship an AI-Assisted Full-Stack App.
- `workshop-3/`: Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents.
- `workshop-4/`: DevOps and Observability for AI-Built Apps.

Pre-Course Live Q&A and Course Launch do not have channel-specific post files yet. Add their posts under new event folders using the same event/channel structure.

## Filing Rules

- File a post under the event that provides its primary angle and CTA.
- Keep posts with only a secondary event mention in the main `social-media/` folder.
- Use channel folders such as `linkedin/`, `x/`, `telegram/`, `slack/`, `newsletter/`, `youtube-community/`, and `youtube-description/`.
- Keep combined Telegram and Slack sequences in `telegram-slack/`.
