# Post

On August 18, we are running Workshop 4 of AI Dev Tools Zoomcamp 2026:

DevOps and Observability for AI-Built Apps

The previous workshop ended with an app that deploys automatically when tests pass. This workshop picks up from there and asks the next production question: how do we know whether the deployed app still works?

Alexey will build the loop around one AI-built app:

- Instrument one important endpoint with OpenTelemetry
- Connect metrics, logs, and traces through a Collector
- Use Prometheus, Loki, Tempo, and Grafana
- Write one alert with symptom, dashboard link, deployed version, and runbook
- Collect a bounded evidence packet with read-only queries
- Run Codex or Claude Code headless as an investigator
- Keep authorization outside the model with action allowlists and autonomy levels
- Verify recovery and audit the code and response trail

Grace Lordel Domisiw and Alexey Grigorev will host the session.
