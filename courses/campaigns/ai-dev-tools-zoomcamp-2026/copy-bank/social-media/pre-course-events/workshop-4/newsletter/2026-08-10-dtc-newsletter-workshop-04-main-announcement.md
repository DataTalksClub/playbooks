## Free workshop: DevOps and Observability for AI-Built Apps

Join us on August 18 for Workshop 4 of AI Dev Tools Zoomcamp 2026:

DevOps and Observability for AI-Built Apps

The previous workshop ended with an app that deploys automatically when the tests pass. That gets the app online, but it does not tell you whether it still works.

This workshop focuses on the production feedback loop around an AI-built app. Alexey Grigorev will show how to observe user impact, alert with context, investigate from evidence, authorize a bounded response or escalation, verify recovery, and audit the code and response trail.

You will see how to instrument one important endpoint with OpenTelemetry and run the telemetry pipeline behind a Collector, using Prometheus for metrics, Loki for logs, Tempo for traces, and Grafana on top.

The workshop will also put a coding agent inside the incident loop as the first line of support. The agent collects the same evidence an engineer would, compares it with recent changes, and proposes an action. It does not get production credentials. Authorization stays outside the model.

Join to understand how observability, alerting, incident response, permission boundaries, and audit fit together for AI-built applications.
