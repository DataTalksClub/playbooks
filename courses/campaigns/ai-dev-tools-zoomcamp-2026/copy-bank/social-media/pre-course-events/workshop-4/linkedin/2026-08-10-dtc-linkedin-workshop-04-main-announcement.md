# Post

Join us on August 18 for a free live workshop: DevOps and Observability for AI-Built Apps.

The previous workshop ended with an app that deploys automatically when tests pass. That is a good milestone, but production work starts after deployment.

How do you know whether the app still works? Which request failed? Which version introduced the problem? Which evidence should someone collect before involving a model? Which action is the agent allowed to propose, and who authorizes it?

Grace Lordel Domisiw and Alexey Grigorev will host this workshop. Alexey will build a practical incident loop around an AI-built app: OpenTelemetry instrumentation, Prometheus metrics, Loki logs, Tempo traces, Grafana dashboards, useful alerts, runbooks, bounded evidence packets, read-only agent investigation, permission tables, and audit.

Join if you want to ship AI-built apps with visibility, alerts you can trust, and agent workflows that do not require production credentials.

Tuesday, August 18 at 2:00 PM GMT+2. RSVP: https://luma.com/ycsfxigi
