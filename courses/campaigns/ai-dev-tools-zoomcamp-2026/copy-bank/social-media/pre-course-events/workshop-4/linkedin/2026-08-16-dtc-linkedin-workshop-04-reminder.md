# Post

This Tuesday: DevOps and Observability for AI-Built Apps.

In Workshop 4 of AI Dev Tools Zoomcamp, Grace Lordel Domisiw and Alexey Grigorev will host a live session on what happens after an AI-built app is deployed.

Alexey will build the loop for observing user impact, alerting with useful context, investigating from evidence, authorizing a bounded response or escalation, verifying recovery, and auditing the code and response trail.

The workshop will also show how a coding agent can be used as a read-only investigator without production credentials. It can return facts, ranked hypotheses, a proposed action, and uncertainty. Authorization stays outside the model.
