# Post

Good observability should help you answer concrete incident questions:

- What are users experiencing?
- Which request failed?
- Where did it fail?
- Which version is deployed?
- What evidence should we collect?
- What action is safe to take?

In Workshop 4 of AI Dev Tools Zoomcamp, Alexey Grigorev will instrument one endpoint end to end so a metric, trace, and log describe the same failed request.

Then he will show how to collect a bounded evidence packet and run a coding agent as a read-only investigator. The agent can propose an action, but authorization stays outside the model.
