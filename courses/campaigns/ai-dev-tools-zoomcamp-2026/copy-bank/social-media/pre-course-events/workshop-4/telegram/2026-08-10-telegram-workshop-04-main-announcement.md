# Post

On August 18, we are running Workshop 4 of AI Dev Tools Zoomcamp 2026:

DevOps and Observability for AI-Built Apps

The previous workshop ended with an app that deploys automatically when tests pass. This workshop starts from the next question:

How do you know whether the deployed app still works?

Alexey will build a practical loop around an AI-built app:

- Observe user impact
- Alert with context
- Investigate from evidence
- Authorize a bounded response or escalate
- Verify recovery
- Audit the code and the response trail

We will also put a coding agent inside this loop as a read-only investigator. It can collect evidence, compare it with recent changes, and propose an action. It does not get production credentials.
