# Thread

## Post 1

An AI coding tool should not have to reconstruct the project from chat history before every task.

Each stage should produce a checked artifact that records what has already been decided.

## Post 2

The sequence can look like this:

Idea -> product spec -> acceptance criteria -> API contract -> implementation -> tests -> deployment setup

Each output gives the next task explicit context and gives the developer something concrete to review.
