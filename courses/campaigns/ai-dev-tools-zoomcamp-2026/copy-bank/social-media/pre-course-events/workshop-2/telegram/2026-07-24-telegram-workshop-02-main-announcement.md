# Post

On August 3, we are running Workshop 2 of AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

This workshop is for people who already use AI coding tools but are still working out how to use them for a complete project.

Generating the first version is usually the easy part. The rest of the work is turning the idea into clear requirements, keeping the generated pieces consistent, checking that the application behaves as expected, and getting it ready to deploy.

Alexey will take one application through this entire process. At each stage, he will explain what to ask AI to do, what context to give it, and what the developer needs to review and test before moving on.

Join if you want a practical development sequence you can use for your own applications. You will see how to move from an idea to a project that another developer can run, inspect, test, and continue working on.
