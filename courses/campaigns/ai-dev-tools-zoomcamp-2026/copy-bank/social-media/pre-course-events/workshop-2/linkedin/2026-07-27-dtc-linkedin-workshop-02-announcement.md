# Post

One week from today, we are running Workshop 2 of AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

The session is designed for developers who already use AI to generate code but want a clearer way to manage a complete application.

Alexey Grigorev will take one project from idea to deployment and explain the decisions behind each step. You will see what to define before asking AI to implement something, how to give the next stage the right context, and what to review and test before continuing.

Join if you want to move beyond disconnected prompts and organize AI-assisted work into a development process you can repeat.

You will leave with a practical way to:

- Turn an application idea into clear implementation work
- Keep generated changes consistent as the project grows
- Decide when to review, test, debug, and move to the next stage
- Carry a local prototype through to deployment
