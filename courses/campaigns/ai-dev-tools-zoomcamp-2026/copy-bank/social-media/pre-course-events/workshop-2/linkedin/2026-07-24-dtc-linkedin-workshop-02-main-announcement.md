# Post

Join us on August 3 for the second free workshop in the AI Dev Tools Zoomcamp 2026 series:

Build and Ship an AI-Assisted Full-Stack App

This workshop is for developers who can use AI to generate code but want a clearer process for turning that code into a complete application.

Alexey Grigorev will take one project from the initial idea to deployment. Instead of treating the frontend, backend, tests, and infrastructure as separate tasks, he will show how the output of each stage guides the next one.

By joining, you will learn how to:

1. Give AI coding tools enough structure to work on a larger project.
2. Keep requirements and technical decisions consistent as the application grows.
3. Review, test, and debug each stage before shipping the result.

You will leave with a development sequence you can apply to your own full-stack projects, including the final project in AI Dev Tools Zoomcamp.
