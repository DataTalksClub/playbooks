# Post

On August 3, I am running the second free workshop for AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

This workshop is about the gap between getting AI to generate code and finishing an application you understand and can ship.

During the workshop, I will take one application from the initial idea to deployment. At each stage, I will explain:

- What I need to define before asking AI to implement something
- What I ask the AI tool to produce
- How that output becomes context for the next step
- What I review and test before continuing

You will see how the product spec, API contract, tests, and deployment setup work together as one development process that you can reuse for your own applications.
