# Post

Next Monday, we are running Workshop 2 of AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

This workshop is for developers who use AI coding tools for individual tasks but do not yet have a clear process for a complete project.

Alexey will take one application from the initial idea to deployment. At each stage, he will explain:

- What the developer needs to decide first
- What to ask the AI tool to produce
- How that output guides the next stage
- What to review, test, and debug before continuing

Join to see how separate AI-assisted tasks become one development process. You will leave with a sequence you can reuse for your own applications and for the course final project.
