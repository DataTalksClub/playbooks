Workshop 2 is this Monday.

Build and Ship an AI-Assisted Full-Stack App

Here is one of the problems we will work through:

The frontend sends a request to create an account. The backend responds with "Not Found".

First, make the failure reproducible:

- Reproduce the issue
- Check the OpenAPI contract
- Write a backend test that fails
- Fix the implementation
- Run the test again
- Verify the complete flow from the frontend

The test stays in the project and catches the same regression later.

This is one part of the end-to-end workflow we will cover, from product spec and frontend to Docker, deployment, and CI/CD.
