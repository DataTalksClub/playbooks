## Building a complete application with AI coding tools

On August 3, I am running the second free workshop for AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

AI coding tools make it easy to start a project. You describe a page or a feature and get working code quickly. But a complete application requires more than a sequence of prompts.

The requirements need to survive from the first specification to the deployed application. The frontend and backend need to follow the same contract. The tests need to check the behavior you actually wanted. When something fails, you need enough structure to find the problem instead of generating another version and hoping it works.

Before the course starts, I want to demonstrate this entire process once with a single application. I will show what I ask AI to do at each stage, what information I carry into the next stage, and what I check before I continue.

This is useful if you already use AI for code generation but do not yet have a clear process for larger projects. You will see how to move from an idea to a working application without losing track of the requirements, architecture, tests, or deployment.

The workshop previews Module 2 and the process learners will later use for the final course project.
