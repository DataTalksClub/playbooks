## Free workshop: Build and Ship an AI-Assisted Full-Stack App

Join us on August 3 for Workshop 2 of AI Dev Tools Zoomcamp 2026.

AI coding tools make it easy to create the first version of a feature or application. The harder part is carrying one set of requirements through the entire project and knowing what to check before you ship it.

In this live workshop, Alexey Grigorev will take one application from idea to deployment. He will show how to organize the work so that each generated output gives the next step useful context, while the developer keeps control of the decisions, review, testing, and debugging.

Join if you want to understand:

- How to turn a vague app idea into work an AI coding tool can implement
- How to keep the generated parts consistent as the project grows
- How to verify the result before moving from a local prototype to deployment

You will see a complete development sequence you can reuse for your own applications and for the AI Dev Tools Zoomcamp final project.
