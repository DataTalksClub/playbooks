## AI Dev Tools Zoomcamp: Workshop 2

AI Dev Tools Zoomcamp starts on August 31.

This week we are preparing for Workshop 2:

Build and Ship an AI-Assisted Full-Stack App

The workshop shows how AI tools fit into a complete development workflow:

- Start from a product idea
- Write a short spec
- Define acceptance criteria
- Build a frontend
- Define an OpenAPI contract
- Implement a backend
- Add database support
- Add tests
- Containerize the app
- Prepare deployment and CI/CD

This is the kind of workflow learners will practice in the cohort and later apply to the final project.
