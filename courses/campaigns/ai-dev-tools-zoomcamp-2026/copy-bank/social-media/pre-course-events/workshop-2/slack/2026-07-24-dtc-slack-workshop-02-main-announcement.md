# Post

On August 3, we are hosting the second free workshop for AI Dev Tools Zoomcamp 2026:

Build and Ship an AI-Assisted Full-Stack App

This session is for anyone who can get AI to generate code but is less certain about how to organize a complete project around it.

Alexey will take one application from the initial idea to deployment. Along the way, he will explain what the developer needs to define, what AI can implement, and what must be reviewed, tested, and debugged before continuing.

Join to see how to:

- Give AI coding tools useful context instead of restarting from a new prompt at every stage
- Keep requirements and technical decisions consistent across the project
- Know when generated output is ready for the next step
- Move from a local prototype to an application that can be tested and deployed

The goal is to give you a development sequence you can reuse for your own applications. The session will be live on YouTube and include time for Q&A.
