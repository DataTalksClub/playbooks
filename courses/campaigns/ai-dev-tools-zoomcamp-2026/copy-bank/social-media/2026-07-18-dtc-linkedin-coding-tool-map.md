# Post

AI developer tools are easier to use when you stop treating them as one category.

In AI Dev Tools Zoomcamp, we focus on using different tools at the parts of the workflow where they fit.

Module 1 is about AI-native developer workflow:

use AI tools deliberately, with context, constraints, verification, and human review.

A practical map:

1. Chat assistants

Examples: ChatGPT, Claude, Gemini, Microsoft Copilot chat, DeepSeek chat.

Good for architecture discussion, explaining code, debugging ideas, design trade-offs, writing specs, reviewing pasted diffs, and learning unfamiliar libraries.

2. Terminal-based coding agents

Examples: Claude Code, Codex CLI, Gemini CLI, Aider.

Good for existing repos, multi-file edits, running tests, fixing lint/type errors, small refactors, debugging from logs, and creating commits.

3. Agentic IDEs and desktop workbenches

Examples: Cursor, Windsurf, VS Code Copilot agent mode, Zed agent panel, Claude Code Desktop/Web, Google Antigravity.

Good for interactive coding, UI changes, exploring a repo visually, reviewing diffs, running an app, and browser-based checks.

4. Cloud and GitHub-native agents

Examples: GitHub Copilot coding agent, Codex cloud-style workflows, Claude Code web/background sessions, Devin-like tools.

Good for assigning issues, background PRs, repo maintenance, documentation updates, and low-to-medium complexity tasks.

5. Project bootstrappers

Examples: Lovable, Bolt, Replit Agent, v0-style UI generators.

Good for fast prototypes, landing pages, CRUD apps, UI mockups, demo apps, and first drafts of frontend code.

The course is not about picking one tool and using it for everything.

It is about choosing the right tool for the task, giving it enough project context, reviewing the output, testing the result, and documenting what was delegated to AI.
