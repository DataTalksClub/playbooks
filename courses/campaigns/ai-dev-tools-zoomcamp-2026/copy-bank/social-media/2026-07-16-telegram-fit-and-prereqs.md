# Post

Who is AI Dev Tools Zoomcamp for?

It is for people who already write some code and want to use AI developer tools in a more structured way.

Good fit:

- Software engineers
- ML engineers
- MLOps engineers
- AI engineers
- Data scientists
- Data engineers
- Analysts who write code
- Technical students with programming basics

You should know:

- Basic programming
- Command line basics
- Git/GitHub basics

You do not need:

- Prior AI tools experience
- Django experience
- Web development experience
- A GPU
- A powerful machine

The live cohort starts on August 31.
