# Post

In AI Dev Tools Zoomcamp, the final outcome is not "I tried a few AI coding tools."

The outcome is a complete project that another person can run, inspect, test, and understand.

That usually means:

- A clear problem description
- Frontend
- Backend
- API contract
- Database or persistent storage
- Tests
- Docker or Docker Compose
- Deployment
- README with setup, run, test, and deployment instructions
- Documentation of how AI tools were used

This is why Workshop 2 is important.

It is about the full-stack workflow:

idea -> spec -> frontend -> OpenAPI -> backend -> tests -> Docker -> deployment

AI can help with each step.

But the developer still owns the contract, the tests, the integration, the review, and the documentation.
