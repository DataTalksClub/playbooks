# Post

You do not need prior AI coding tools experience to join AI Dev Tools Zoomcamp.

You do need programming basics.

The course is beginner-friendly for programmers, not for complete coding beginners.

You should be comfortable enough to:

- Write basic code in Python, JavaScript, TypeScript, or a similar language
- Use the command line
- Work with Git and GitHub
- Clone a repository
- Run commands
- Read errors
- Debug and test changes

You do not need:

- Previous Cursor, Copilot, Claude Code, Codex, MCP, or agent experience
- Django experience
- Web development experience
- A powerful machine
- A GPU

The course teaches AI-assisted software development workflows:

- Giving tools useful context
- Reviewing generated code
- Testing changes
- Building frontend/backend features
- Using agents and MCP
- Shipping with deployment, CI/CD, security, and audit checks
