AI Dev Tools Zoomcamp: Module 6 starts

This week we start Module 6: Automation with Low-Code and No-Code AI.

This module shows that AI development is not only code inside an IDE. Some useful workflows are better expressed as automations that connect tools, content, data, and AI steps.

In this module, you will:

- Install n8n.
- Build low-code and no-code AI workflows.
- Connect tools, content, data, and AI steps.
- Create posts for LinkedIn.
- Tailor a CV for a specific position.
