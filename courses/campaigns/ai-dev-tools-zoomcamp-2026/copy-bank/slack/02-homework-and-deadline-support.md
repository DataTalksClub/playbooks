## Debugging Reminder

When AI-generated code fails, the useful question is not only "how do I fix this?"

Try to answer:

- What changed?
- Which command fails?
- Is the error from installation, runtime, tests, database, API, frontend, or deployment?
- Can you reproduce it from a clean checkout?
- Did the AI tool add code you did not inspect?

This is the course skill. The AI tool can help, but you still need the engineering loop.

Good reflection questions:

- Which AI tool was actually useful?
- Which generated change did you need to fix manually?
- Which command or test caught a problem?
- What would you do differently next time?
