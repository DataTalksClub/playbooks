# MLOps Zoomcamp Event Copy

This folder holds the reusable event templates for MLOps Zoomcamp.

## Past Events

Published copy from 3 past MLOps Zoomcamp workshops, launches, and live Q&A sessions is archived in [`events-archive/mlops-zoomcamp/`](../../../../events-archive/mlops-zoomcamp/), with the full index at [`events-archive/README.md`](../../../../events-archive/README.md).

Read those before writing copy for a new cohort. The module framing, the "Thinking About MLOps Zoomcamp?" block, and the speaker bio are reused almost verbatim from one cohort to the next.

Workshops adjacent to this course but not part of its series — sponsor sessions and industry webinars — are filed under [`events-archive/community/`](../../../../events-archive/community/) with a `Related course` line in their header.
