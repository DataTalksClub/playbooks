## What We'll Cover

Alexey will walk through:

- The pipeline you'll build toward: ingestion, storage, warehouse modeling, transformations, batch or streaming work, and a dashboard
- The first week: Docker, PostgreSQL, setup decisions, and why getting your environment working is already real progress
- The cohort rhythm: homework, deadlines, scoring, leaderboard, peer review, and certificates
- The tool map: where Terraform, Google Cloud, BigQuery, orchestration, dbt, Spark, and streaming fit in the bigger picture
- The support system: Slack, Telegram updates, FAQ, setup help, and how to ask questions that get useful answers

There will also be time for live questions, so bring anything about prerequisites, cloud setup, SQL, project scope, or keeping up with the schedule.

## Starting DE Zoomcamp?

DE Zoomcamp is a free hands-on course for people who want to learn modern data engineering by building real pipelines. The course takes you from local development to cloud warehouses, orchestration, transformations, batch processing, streaming, and project delivery.

**You should be comfortable with:**

- command line basics
- basic programming concepts
- SQL fundamentals
- Git basics

**You don't need:**

- previous data engineering experience
- prior cloud experience
- advanced Python
- a degree
