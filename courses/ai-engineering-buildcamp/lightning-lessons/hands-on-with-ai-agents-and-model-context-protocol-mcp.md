## What you'll learn

### Build AI agents

Create agents that think and use tools for completing user assignments.

### Engineer with PydanticAI and OpenAI Agents SDK

Get hands-on with the libraries that power production-grade AI agents.

### Extend tools with MCP (Model-Context Protocol)

Build your own MCP server to plug in new tools into your agents seamlessly.

## Why this topic matters

AI agents are transforming how work gets done, automating research, analysis, and decision-making at scale. Understanding how to create them gives you a competitive edge, letting you work on smarter tools, streamline processes, and bring advanced AI capabilities into real-world applications.
