1/5

Even with coding agents, technology choice is still architecture work.

In the workshop, I asked the agent for multiple stack options. Then I challenged them.

2/5

I chose Django mostly because I know it well.

I can read it, review it, debug it, and maintain it after the agent finishes.

3/5

The agent can suggest a stack.

You still own the hosting model, dependency choices, background jobs, APIs, versions, and operational complexity.

4/5

Useful questions:

Is this too heavy for the MVP? Can we defer this? Do we need this dependency? Is the version current? Can I maintain it?

5/5

AI coding does not remove architecture decisions. It makes them more important.
