1/5

Project-level specs are not enough for coding agents.

Each feature still needs grooming.

This is the product manager role in the workflow.

2/5

A good groomed issue has:

Goal, description, acceptance criteria, edge cases, and out-of-scope items.

3/5

Acceptance criteria should be checkable.

Someone should be able to point at the screen and say:

"Yes, this passes."

or

"No, this fails."

4/5

Out-of-scope items matter too.

Agents often add reasonable extras. For an MVP, those extras become maintenance work.

5/5

Feature specs remove ambiguity before implementation starts.
