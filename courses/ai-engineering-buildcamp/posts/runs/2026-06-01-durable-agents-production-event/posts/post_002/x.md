Your agent calls a tool to create a support ticket.

The request times out.

Should it retry?

If the ticket was already created, the retry can create a duplicate.

2/5

This is one of the places where tool calling alone is too thin.

You need the workflow to know what was attempted, what failed, and whether retrying is safe.

In production, they decide whether the agent creates duplicate tickets, sends duplicate messages, or repeats an external action.
