1/7

One useful way to work with coding agents:

Get a working version first.

Then simplify it.

2/7

In the Lambda workshop, the agent produced a version that worked locally.

I did not understand half of the code at first.

That was okay as a checkpoint.

3/7

The next step was not to ship it blindly.

The next step was to inspect it.

4/7

Questions to ask:

- Why is this file needed?
- Which parts are Lambda-specific?
- Which parts are app logic?
- Can this be simpler?

5/7

Agents often create code that works but is more complicated than necessary.

This happens even more with platform details.

6/7

The workflow:

1. Get it running
2. Commit the state
3. Ask for explanations
4. Simplify
5. Keep only what has a clear reason

7/7

Working code is a checkpoint, not the finish line.
