1/6

AI engineers are expected to use coding agents.

They are also expected to understand the code.

2/6

You cannot say:

"The agent implemented it. I have no idea how it works."

The ownership is still yours.

3/6

A useful workflow:

- Let the agent help with syntax and platform details
- Review the changes
- Ask questions
- Document the final path
- Clean up the docs

4/6

This matters a lot for infrastructure.

The path may include failed deploys, odd flags, platform details, and small gotchas.

5/6

If you do not document it, you only have a working repo and a vague memory.

If you document it, you get reusable knowledge.

6/6

Next time, you can give the document to yourself or to an agent and say:

"Do something similar."
