1/8

For an AI engineer take-home assignment, the README is not an afterthought.

It is part of the interview.

2/8

In the workshop, we built:

- scoped assignment
- data sources
- CLI agent
- tests
- evals
- Telegram bot
- limitations

3/8

But a hiring manager may not read the code first.

They may have only a few minutes.

So the README needs to tell the story.

4/8

Include:

- what it does
- assignment
- decisions
- how to run it
- demo/screenshots
- data sources
- safety boundaries

5/8

Also include:

- tests
- evals
- monitoring
- known limitations
- next improvements

6/8

Be honest about AI-generated code.

It is normal now that candidates use coding agents.

7/8

The interesting question is not:

"Did you use AI?"

It is:

"Do you understand what it produced, where it is weak, and how you would improve it?"

8/8

A polished README helps answer that before the defense interview even starts.
