# idea_006: Your README is part of the interview

Angle: For a take-home or portfolio project, the README is often the first artifact a hiring manager reads.

Source moments:
- 01:50:29-01:52:46: The README should explain the storyline, decisions, limitations, generated code, and follow-up work.
- 02:02:30-02:05:10: Reviewers may only have a few minutes, so the README needs to show what was built, what was not built, tests, evals, monitoring, screenshots, and next steps.

Post notes:
- Make it a checklist-style career post.
- Encourage reusing unpaid take-home work as a portfolio project when appropriate.
- Stress honesty about generated code and limitations.
