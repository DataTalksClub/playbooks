1/4

Your coding agent is already producing a dataset.

Claude Code, Codex, Copilot, and similar tools store traces: token usage, models, inputs, outputs, cache, projects, and tool calls.

2/4

The raw files are useful, but they are usually JSON or JSONL.

You can inspect them manually once. After that, you want a pipeline and a dashboard.

3/4

In Alena Astrakhantseva's workshop, we ingest local agent traces with dlt, load them to DuckDB, and explore usage by day, model, and project.

4/4

This is agent observability as a data engineering problem: traces, ingestion, schema, validation, reports.
