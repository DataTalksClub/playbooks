1/5

A useful mental model for coding agents:

Skills describe what to do.

Tools do the repeated work.

2/5

A skill can be markdown:

When to use a file-system pipeline. When to use a REST API pipeline. How to debug. How to validate the data.

3/5

A tool is executable and deterministic:

Read a file. Count rows. Read a table. Run a pipeline. Inspect schema. Query the destination.

4/5

This matters for AI engineering workflows.

The model should choose the workflow and interpret results. Reusable code should handle repeated operations.

5/5
