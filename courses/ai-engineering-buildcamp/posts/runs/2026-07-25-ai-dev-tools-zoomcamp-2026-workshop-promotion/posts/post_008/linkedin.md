A coding agent becomes more useful when it has the right instructions, tools, permissions, and repeatable workflows.

This is why Module 3 of AI Dev Tools Zoomcamp focuses on Coding Agent Capabilities: MCP, Skills, Plugins, and Custom Agents.

A practical workflow needs a few simple controls:

- Use project instructions for repository-specific behavior
- Use MCP when the agent needs external tools or context
- Use skills and commands for repeatable workflows
- Use hooks and permissions to add review points around risky actions

The goal is not to slow down AI-assisted work.

The goal is to make the work reproducible enough that you can review it, test it, debug it, and ship it with confidence.
