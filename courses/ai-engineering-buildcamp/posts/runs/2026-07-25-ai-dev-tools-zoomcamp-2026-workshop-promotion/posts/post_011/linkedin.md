AI-assisted projects still need security scanning, audit trails, incident investigation, and deployment discipline.

This is why Module 4 of AI Dev Tools Zoomcamp focuses on Open-Source AI Tools for Security, Audit, and DevOps.

A practical workflow needs a few simple controls:

- Review generated code like any other production change
- Make scanners available before the agent asks for deployment
- Record what changed, which tools ran, and which checks passed
- Use AI for investigation, but keep policy and approval explicit

The goal is not to slow down AI-assisted work.

The goal is to make the work reproducible enough that you can review it, test it, debug it, and ship it with confidence.
