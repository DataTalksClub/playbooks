## About the guide

Create a coding agent that scaffolds and edits a Django app from a single prompt.

It's for developers who want a practical, minimal path from “chatbot” to “agent,” without heavy frameworks.

Build a Lovable.dev/Bolt.new agent in an afternoon. No prior agent experience needed.

## What’s inside

- A working app generated by your agent
- Function Calling: turn a chatbot into an agent
- Tools for file I/O, search, and code exec
- Ready-to-clone Django template + Make/UV setup
- Full code snippets
