We start Module 5, the final module, on Coding Agent Capabilities.

Across the course, you have used coding agents for planning, implementation, testing, deployment, and operations. This module shows how to make useful agent behavior reusable without giving every task the same context and permissions.

We cover:

- Reusable skills and specialized subagents
- Which instructions and tools each task needs
- Where to set boundaries for an agent
- How to make the result verifiable by another person
