# Module 5: Coding Agent Capabilities

Hello there,

So far, you have used coding agents across planning, implementation, testing, deployment, and operations. In the final module, you will focus on making useful agent behavior reusable.

Start with the [Module 5 materials](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/05-agent-capabilities). The [recording](https://www.youtube.com/watch?v=t8OrAjNO2Zs) and the [companion article on reusable skills and specialized subagents](https://aishippingblog.com/p/coding-agent-building-blocks-reusable) show how these pieces fit into practical development workflows.

## What You Will Practice

Choose a repeated engineering task and ask:

- What instructions should persist across runs?
- Which tools does the agent need?
- What context should be loaded only when relevant?
- Does the task belong in a reusable skill or a specialized subagent?
- What output can another person verify?
- Which decisions and permissions must remain human-controlled?

There is no graded Homework 5 in the 2026 cohort. Use this week to create or improve one reusable capability and apply it where it genuinely helps your project.
