# Module 3: Test, Containerize, and Deploy

Hello there,

You now have a full-stack application. This week, the focus shifts from adding features to making the application testable, reproducible, and deployable.

Open the [Module 3 materials](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/03-deployment) when you are ready to begin. The [recording](https://www.youtube.com/watch?v=gxt5ZDVnBMM) and [companion deployment article](https://aishippingblog.com/p/deploy-a-full-stack-app-with-ai-coding) are useful if you want to see the workflow before applying it to your own project.

## What You Will Practice

This module is about building confidence in the application outside the original development session. You will work on the checks, packaging, documentation, and deployment steps that let another person run the system and understand whether it works.
