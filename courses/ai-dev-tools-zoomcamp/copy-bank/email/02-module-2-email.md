# Module 2: Build and Ship a Full-Stack Application

Hello there,

In Module 1, you designed a workflow that an agent could execute and another agent could verify. Now it is time to apply that discipline to a larger build.

In [Module 2](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/02-development), you will create a real-time collaborative coding interview platform. The application needs a frontend and backend, shared editing, syntax highlighting, safe browser-based code execution, tests, containers, and a public deployment.

The [recording](https://www.youtube.com/watch?v=x9dq5nBpDg8) walks through the development workflow, and the [companion article](https://aishippingblog.com/p/build-and-ship-a-full-stack-app-with) gives you another way to review the main ideas.

## What You Will Practice

You will:

- Build frontend and backend behavior with AI assistance.
- Add integration tests before assuming the parts work together.
- Run the client and server through one development command.
- Add syntax highlighting and browser-based code execution.
- Package the application in one container.
- Deploy it and document how to run it.
