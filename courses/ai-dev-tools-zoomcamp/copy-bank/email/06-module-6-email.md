Hey there,

This week, we start [Module 6: Automation with Low-Code and No-Code AI](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/06-automation-lowcode).

## What to Work On

There is no graded homework documented for this module in the course notes we have.

Use this week to run the examples and think about where automation fits into your own work:

- Which repeated task could be automated?
- Which tools need to be connected?
- Where does an AI step help?
- What needs to be reviewed manually?
- How would you document the workflow so another person can run it?
