# Module 4: DevOps and Observability for AI-Built Apps

Hello there,

Your application can now be built and deployed. This week, you will work on the feedback loop that tells you what happens after real users begin interacting with it.

The [Module 4 materials](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp/tree/main/04-devops) cover DevOps and observability for AI-built applications. You can follow the [recording](https://www.youtube.com/watch?v=YkxLo_FRoQw) and use the [companion article](https://aishippingblog.com/p/devops-and-observability-for-an-ai) when applying the ideas to your own system.

## What You Will Practice

You will think about:

- What evidence the application should produce.
- Which failures should trigger an alert.
- What context is needed to investigate a problem.
- How deployment and operational workflows should be documented.
- Where a coding agent can help safely.
- Which production permissions an agent should never receive.
