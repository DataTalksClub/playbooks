## Short Course Description

AI Dev Tools Zoomcamp is a free hands-on course about using AI coding tools in real software development workflows.

You will practice with AI assistants, coding agents, MCP, OpenAPI, tests, CI/CD, deployment, and automation. The goal is to build useful software with AI support while still reading, running, debugging, testing, and documenting the code.

## What You Will Build

During the course, you will work toward a complete application of your own.

A typical final project includes:

- Frontend.
- Backend.
- API contract or OpenAPI specification.
- Database or persistent storage.
- Tests.
- Docker or Docker Compose.
- Deployment or clear run instructions.
- Documentation of AI tools, prompts, agents, MCP, or automation used during development.

## Course Scope Note

This course is about AI-assisted software development.

It is not primarily about RAG, LangChain, vector databases, model training, or fine-tuning. The focus is using AI tools to plan, build, review, test, deploy, and document software.
