## What a Project Involves

Useful when a post needs to describe the work rather than link to it. Source: `ml-zoomcamp/course.yaml`.

- A dataset the student chooses, not one used in the lectures or homework
- Data preparation, cleaning, and EDA with feature importance analysis
- Training several models and tuning them, then selecting one
- Notebook logic exported into scripts
- A deployed model. A notebook-only project does not pass
- Documentation good enough that someone else can run it

Deployment routes students actually use: FastAPI in Docker, AWS Lambda with ONNX Runtime, Streamlit or Gradio demos, Kubernetes, Flask or BentoML, KServe.

Projects are scored against a 16-point rubric and reviewed by three peers.

## Before Featuring an Individual Project

Project submissions include public GitHub links, but a public repository is not permission to feature someone in marketing. Ask the student first, and prefer the case studies and the gallery above. Do not paste submission records into this repository: they contain student emails.
