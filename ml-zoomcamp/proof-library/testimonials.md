# ML Zoomcamp: Testimonials

Learner quotes cleared for use in launch copy.

## Status

Empty. The platform does not store testimonials, so unlike the stats and project files this one cannot be filled from the course management agent. It needs a human pass.

## Where to Collect From

- Blog posts written with learners. Two ML Zoomcamp learner stories are already published, linked in [student-projects.md](student-projects.md), and quoting from them is safe because the learner agreed to the write-up.
- The `#course-ml-zoomcamp` Slack channel, especially end-of-cohort messages.
- Certificate and graduation posts on LinkedIn where learners tag the course.
- The post-cohort retrospective.

## Rules

- Get permission before quoting anyone, even from a public post. A public message is not consent to appear in marketing.
- Record the source link next to every quote so it can be checked later.
- Use the learner's name only if they agreed to it being used.
- Prefer quotes that say something concrete about what the learner built or changed, over generic praise.

## Format

```
> Quote text.

- Name, or Anonymous
- Source: URL
- Permission: how and when it was given
- Cohort: year
```
