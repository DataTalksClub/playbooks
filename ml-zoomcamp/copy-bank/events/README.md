# ML Zoomcamp Event Copy

This folder holds the reusable event templates for ML Zoomcamp.

## Past Events

Published copy from 6 past ML Zoomcamp workshops, launches, and live Q&A sessions is archived in [`events-archive/ml-zoomcamp/`](../../../events-archive/ml-zoomcamp/), with the full index at [`events-archive/README.md`](../../../events-archive/README.md).

Read those before writing copy for a new cohort. The module framing, the "Thinking About ML Zoomcamp?" block, and the speaker bio are reused almost verbatim from one cohort to the next.

Workshops adjacent to this course but not part of its series — sponsor sessions and industry webinars — are filed under [`events-archive/community/`](../../../events-archive/community/) with a `Related course` line in their header.
