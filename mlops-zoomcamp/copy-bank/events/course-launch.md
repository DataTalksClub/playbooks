## What We'll Cover

Alexey will walk through:

- The system you'll build toward: experiment tracking, model registry, orchestration, deployment, monitoring, tests, CI/CD, and reproducible infrastructure
- The first week: how to set up your environment and reconnect the course to the ML workflow you already know
- The cohort rhythm: homework, deadlines, scoring, final project, peer review, and certificates
- The project path: how to choose realistic tools for tracking, orchestration, deployment, monitoring, and cloud or local infrastructure
- The support system: Slack, Telegram updates, FAQ, troubleshooting, and community support

There will also be time for live questions, so bring anything about MLflow, Docker, cloud setup, orchestration tools, monitoring, or final project scope.

## Starting MLOps Zoomcamp?

MLOps Zoomcamp is a free hands-on course for people who already know the basics of machine learning and want to learn how to run ML systems more reliably. It focuses on the production side: tracking, pipelines, deployment, monitoring, testing, code quality, CI/CD, and infrastructure.

You should know Python, command line basics, Docker basics, and the usual ML workflow. You do not need previous MLOps experience, DevOps experience, cloud experience, deep math, or a degree.
