## What We'll Cover

Alexey will walk through:

- What you'll learn: experiment tracking, model registry, orchestration, deployment, monitoring, testing, CI/CD, and infrastructure as code
- How the course works: videos, homework, deadlines, final project, peer review, and certificate path
- What you'll build: an end-to-end MLOps project with a model, pipeline, deployment path, monitoring, and reproducible setup
- How to choose your path: local vs cloud setup, orchestration tools, monitoring options, and practical trade-offs
- Where to get help: DataTalks.Club Slack, Telegram updates, FAQ, and community support

You'll also hear practical advice on how to handle the engineering-heavy parts without trying to master every tool at once.

## Is This Course for You?

MLOps Zoomcamp is a free hands-on course for people who already know the basics of machine learning and want to learn how to run ML systems more reliably. It focuses on the production side: tracking, pipelines, deployment, monitoring, testing, code quality, CI/CD, and infrastructure.

You should know Python, command line basics, Docker basics, and the usual ML workflow. You do not need previous MLOps experience, DevOps experience, cloud experience, deep math, or a degree.
