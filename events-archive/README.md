# Past Event Copy Archive

Published descriptions of DataTalks.Club workshops, launches, and live Q&A sessions, scraped from their Luma pages and kept verbatim. Use them when writing copy for a new cohort: the structure, the module framing, and the recurring blocks all carry over.

Each file has a metadata header (type, date, instructor, Luma link, course and module) followed by the description exactly as it was published, typos included.

Events are grouped by the course they teach. Sponsor talks, hackathons, and career webinars sit in `community/`; where one is adjacent to a course, its header carries a `Related course` line.

Source: `_data/events.yaml` in the [datatalksclub.github.io](https://github.com/DataTalksClub/datatalksclub.github.io) repo, which lists every event with its Luma URL.
