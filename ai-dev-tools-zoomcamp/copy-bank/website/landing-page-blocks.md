## Outcome Block

By the end of the course, you will have practiced a full AI-assisted development workflow:

- Plan an application and use AI tools to build it step by step.
- Connect frontend and backend through an API contract.
- Add database support, tests, containers, deployment, and CI/CD.
- Use MCP and coding agents with a clearer understanding of tools and context.
- Document how AI helped, where it failed, and what you reviewed manually.

The target outcome is a complete deployed application that you can explain and reproduce.

## What You Will Learn

- How different AI coding tools behave on real development tasks.
- How to give AI tools useful project context.
- How to review, debug, and test generated code.
- How to work with OpenAPI, FastAPI, React, databases, Docker, Render, and GitHub Actions.
- How MCP connects assistants to tools, docs, and actions.
- How coding agents read files, write files, run commands, and use tool results.
- How AI can support PR review, tests, CI/CD, release notes, and automation.

## Prerequisites

You should have:

- Basic programming ability in Python, JavaScript, or a similar language.
- Comfort with the command line.
- Git and GitHub basics.

You do not need:

- Prior AI coding tools experience.
- Web development experience.
- Django experience.
- A powerful machine or GPU.

## Project Block

The final project is a complete application of your own.

A strong project includes:

- A clear problem.
- Frontend and backend.
- API contract or OpenAPI spec.
- Database or persistent storage.
- Tests.
- Docker or Docker Compose.
- Deployment or reproducible run instructions.
- A README that explains the app and the AI-assisted workflow.
