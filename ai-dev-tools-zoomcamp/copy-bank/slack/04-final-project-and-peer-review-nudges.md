# Final Project and Peer Review Nudges

Use these after the module sequence, or earlier when learners start thinking about projects.

## Project Idea Prompt

Final project planning prompt:

What are you thinking of building?

A good project idea has:

- A clear problem.
- A small enough scope.
- A frontend or usable interface.
- A backend or API.
- Some persistent data.
- Tests.
- Deployment or clear run instructions.
- Documentation of how AI tools were used.

## Scope Check

Project scope reminder:

A smaller working app is better than a large unfinished app.

Before adding more features, check:

- Can someone run it from the README?
- Is the API contract documented?
- Is there a backend?
- Is there persistent storage?
- Are there tests?
- Is it deployed or reproducible locally?
- Did you document where AI tools helped and what you reviewed?

If the answer to several of these is no, reduce scope before adding features.

## AI Usage Documentation Prompt

For the final project, do not only document the final app.

Document the workflow:

- Which AI tools did you use?
- What did you ask them to do?
- Where did they help?
- Where did they fail?
- What did you review manually?
- Which tests or commands gave you confidence?
- Did you use AGENTS.md, prompts, MCP, or automation?

This is part of the learning outcome of the course.

## Peer Review Reminder

Certificate reminder:

The final project path requires passing the project and completing the required peer reviews.

When reviewing another project, be practical:

- Can you understand what the app does?
- Can you run it from the README?
- Are setup steps clear?
- Are tests documented?
- Does the app have frontend/backend/API/database pieces where expected?
- Is AI usage explained?
- Is deployment or a demo available?

Good reviews help both people. The reviewer also learns what makes a project reproducible.

## Project Help Thread

Use this thread for final project blockers.

Good project help requests include:

- Repo link.
- What you are trying to make.
- Current status.
- The exact blocker.
- Command, error, or screenshot.
- What you already tried.

Please ask about one blocker at a time. It is much easier for others to help.
