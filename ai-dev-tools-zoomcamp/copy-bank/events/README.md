# AI Dev Tools Zoomcamp Event Copy

This folder holds the events that repeat every cohort, written as templates with placeholders:

- [Pre-course live Q&A](01-yyyy-mm-dd-pre-course-live-qa.md) — schedule about a week before the start date
- [Course launch](02-yyyy-mm-dd-course-launch.md) — runs on the start date

Copy these into `campaigns/<course>-<year>/copy-bank/events/`, rename them with the real date, and fill in the placeholders.

## Cohort Workshops

Workshops are specific to a cohort and its syllabus, so the drafts live in the campaign folder rather than here. This index keeps them findable once the cohort is over.

Reuse them when the same module comes back: the structure, the "What You'll Learn" framing, and the series cross-links carry over even when the tools change.
