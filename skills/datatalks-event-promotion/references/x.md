# X

Use this reference for X deliverables after selecting the account owner in `social-media.md`. The account's subscription determines the format.

## Alexey's X Account

Alexey has X Premium. His post can use the same long-form core copy as LinkedIn, so do not force it into standard 280-character posts or a thread solely because it is for X.

Use `$social-content-studio` for his voice and post construction. Create a platform-specific thread only when the user asks for one or when a thread materially improves the presentation.

## DataTalks.Club X Account

DataTalks.Club does not have X Premium. Apply the standard post limit:

- Every individual post must be 280 characters or fewer.
- Count every URL as 23 characters because X wraps links with `t.co`, regardless of the original URL length.
- Leave a small editing buffer when practical. For a post containing a URL, aim for roughly 260 counted characters rather than exactly 280.
- Deliver every DataTalks.Club X asset as a thread of at least two posts, including short announcements and reminders.
- Do not remove essential context or combine the thread into one post merely because the copy could fit.

Count the final rendered copy, including spaces, punctuation, thread numbering, and the 23-character value for each URL. Do not report a DTC X deliverable as ready until every post has been checked.

## Thread Construction

- Give each post a complete thought and a clear role in the sequence.
- Open with a concrete audience problem, useful context, or direct announcement.
- Use middle posts for practical context, learning outcomes, or speaker/event relevance.
- Put the registration or recording link in the first or final post when possible.
- Include essential date, time, and timezone information in a pre-event thread.
- Repeat a link only when it improves usability.
- Number the posts only when helpful; include the numbering in the character count.

For DataTalks.Club voice and storytelling, read `datatalks-social-media.md`.

## Delivery Check

Return the X copy as clearly separated posts. When practical, include the checked character count beside each DTC post outside the publishable copy. If any post exceeds 280 characters, revise or split it before delivery.
