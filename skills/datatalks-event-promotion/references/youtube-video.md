# YouTube Video Metadata

Use this reference when the campaign calls for a YouTube title, description, pinned comment, or live-to-recording metadata update.

## Title

- Describe the actual video content in clear, searchable language.
- Include the concrete topic, workflow, tool, or outcome viewers will see.
- Keep course or workshop numbering only when it helps identify the series.
- After the live event, update a logistics-heavy live title so it represents the recording's lasting content.
- Avoid clickbait, unsupported outcomes, all caps, and keyword lists.

Do not optimize for search by inventing terms the speaker did not cover. Prefer the language used in the event source, recording, notes, or transcript.

## Description

Use this order when the source supports it:

1. One or two short paragraphs summarizing the problem and what the video covers.
2. The event, workshop, course, or module name.
3. A concise list of the main topics or sections.
4. Recording notes, slides, code, or materials.
5. Relevant course or cohort link.
6. A supplied next-event link.
7. DataTalks.Club community link when relevant.

Put the most useful description of the video before secondary campaign links. Label links clearly and keep each important link easy to find.

## Pinned Comment

Keep the pinned comment focused. Use it for one primary next step:

- Recording notes or materials.
- Course registration.
- The next event.
- A specific discussion question tied to the video.

Include a short reason to open the link. Do not repeat the entire description or stack unrelated CTAs.

## Live And Post-Event Updates

On the event date, use the supplied live stream link and current event facts. After the event, update the title and description using the recording, transcript, notes, or actual session content; do not write a definitive recap from the pre-event description alone.

Preserve existing useful links unless the user asks to remove them. Surface conflicts between the scheduled event details and the recording source instead of silently choosing one.
