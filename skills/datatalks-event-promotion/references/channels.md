# Channels

Use this reference when the user asks for a distribution plan or posting schedule, or when drafting channel-specific deliverables. Channel choice changes both campaign coverage and content format.

When drafting LinkedIn or X deliverables, read `social-media.md` to route by account owner. Then read `linkedin.md` or `x.md`. For DataTalks.Club posts, also read `datatalks-social-media.md`; for Alexey posts, use `$social-content-studio`.

When drafting Telegram announcements, reminders, recaps, or operational lists, also read `telegram.md`.

When drafting newsletter deliverables, read `newsletter.md` to route by owner and recipient. Also read `datatalks-newsletter.md` for DataTalks.Club copy or use `$newsletter-editor` for Alexey's newsletter.

When drafting DataTalks.Club Slack deliverables, read `slack.md`.

When drafting YouTube Community posts, read `youtube-community.md`. For YouTube titles, descriptions, pinned comments, or live-to-recording updates, read `youtube-video.md`.

Choose the channel plan by event category:

- Course-related event: use the detailed course-related plan below.
- General DataTalks.Club event: use the general event defaults below unless the user provides a custom plan.

If the event category is unclear and channels matter, ask whether the event is course-related or general. If channels do not matter for the current task, draft the content without a channel plan.

## Course-Related Events

Use this schedule for course-related DataTalks.Club events.

| Content piece | Timing | Link to include | Channels |
|---|---:|---|---|
| Main announcement | 10 days before the event date | Registration link | Alexey's social media; Alexey's newsletter; DTC social media; DTC newsletter; DTC Slack; YouTube community; Telegram announcements |
| Education post on the event topic | 6 days before the event date | Registration link | Alexey's social media; DTC social media; YouTube community; Telegram announcements |
| Event reminder | 2 days before the event date | Registration link | Telegram announcements; Alexey's social media; DTC social media; DTC Slack; YouTube community |
| Live event announcement | Event date | Live stream link | Update YouTube description; add pinned comment under YouTube recording; update title to reflect the video content and optimize for YouTube SEO |
| Event recap | Within 2 days after the event date | Notes/event recording link | Telegram announcements; Alexey's social media; Alexey's newsletter; DTC social media; DTC newsletter; DTC Slack; YouTube community |
| Repurposed text post(s) | After the event date, as many posts as possible | Notes/event recording link | Alexey's social media; DTC social media; YouTube community |
| Repurposed short video(s) | 5 days after the event date, as many posts as possible | Notes/event recording link | Alexey's social media; DTC social media; YouTube community |

Stage mapping:

- Stage 1 usually covers main announcement, education post on the event topic, event reminder, and live event announcement planning.
- Stage 2 covers event recap, repurposed text posts, and repurposed short-video ideas.
- The live event announcement uses the live stream link and YouTube metadata actions. Do not invent the live stream link.

## General DataTalks.Club Events

General events use a lighter pre-event campaign than course-related events.

### Stage 1: Before The Event

Create the usual main announcement and reminder for:

- Alexey's social media: X and LinkedIn.
- DTC social media: X and LinkedIn.

Adapt both social posts for YouTube Community. Preserve the same core angle and facts, but make the copy feel native to a YouTube Community post rather than copying platform-specific phrasing, formatting, tags, or references to another network.

Announce the event in the DTC newsletter using one of these formats:

- Ordinary general event: include it in the newsletter's community events section. Use the linked event name and one short sentence explaining what readers will learn.
- Sponsored event or workshop: use a separate newsletter block. Include a short introduction of about one or two sentences, a concise list of what participants will learn or do when the source supports one, a short closing of about one or two sentences, and a registration CTA with the link.

Do not turn an ordinary general event into a large standalone newsletter feature unless the user asks for it. Do not compress a sponsored workshop into the one-line community events format when a dedicated block is expected.

Pre-event educational social posts are optional for general events. Create them only when the user requests them or a custom campaign plan includes them.

### Stage 2: After The Event

Use the DTC newsletter system to send a recap to people who registered for the event. Treat this as a registrant follow-up, not automatically as a broadcast to the entire newsletter audience. Include the recording or notes link when available and summarize what they can revisit.

For Alexey's and DTC's social media, create the post-event assets supported by the available recording, transcript, or notes:

- Educational posts based on ideas from the event.
- A recording recap once the recording is available.
- Short videos repurposed from self-contained recording moments.
- Short text posts repurposed from event notes, when notes exist.

Adapt every Alexey/DTC social asset for YouTube Community. Keep the idea and CTA aligned, but adjust length, opening, formatting, and context for a YouTube audience. A YouTube Community adaptation is a channel version of an existing asset, not an additional campaign angle.

### General Event Channel Map

| Content piece | Timing | Link to include | Channels and format |
|---|---:|---|---|
| Main announcement | Before the event | Registration link | Alexey social; DTC social; adapted YouTube Community post |
| Event reminder | Shortly before the event | Registration link | Alexey social; DTC social; adapted YouTube Community post |
| Ordinary event newsletter mention | Before the event | Linked event name | DTC newsletter community events section; one short learning sentence |
| Sponsored workshop newsletter block | Before the event | Registration link | Separate DTC newsletter block with brief context, optional learning list, and CTA |
| Registrant recap | After the event, when recording or notes are available | Recording or notes link | DTC newsletter follow-up to event registrants |
| Recording recap | When the recording is available | Recording link | Alexey social; DTC social; adapted YouTube Community post |
| Repurposed educational text posts | After the event | Recording or notes link when useful | Alexey social; DTC social; adapted YouTube Community posts |
| Repurposed short videos | After the recording is available | Recording link when useful | Alexey social; DTC social; adapted YouTube Community posts |

Use Stage 1 and Stage 2 timing from the relevant stage reference unless the user provides a custom timing plan.

General events usually do not need the full course-related channel spread. Add Telegram, Slack, Alexey's newsletter, or other channels only when the user asks, the event context clearly calls for it, or there is an existing campaign plan that includes them.

## Channel Plan Output

When the user asks for channels or a distribution plan, include a concise table:

```markdown
| Content piece | Timing | Link to include | Channels |
|---|---:|---|---|
| Main announcement | [Timing] | [Registration/link type] | [Channels] |
```

Keep channel planning separate from post copy when that makes the output easier to review.
