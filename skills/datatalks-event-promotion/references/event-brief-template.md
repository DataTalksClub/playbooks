## Missing Information Check

Before drafting, identify any missing details that affect factuality:

- Date, time, or timezone.
- Registration link.
- Speaker role or company.
- Sponsor/product claims.
- Whether the event includes a demo, live build, workshop, panel, or Q&A.
- Claims that require sponsor approval.
- Post-event notes, recording link, transcript, or timestamps when creating recaps, repurposed posts, or short-video ideas.

If a missing detail is not necessary for the draft, proceed and omit it. If it changes the substance of the post, ask for it or return a brief with open fields.
