## Give Snowflake CoWork data it can actually reason over

Data agents are only as good as the data they reason over, and most clickstream data isn't built to serve this purpose. Instead, it’s plagued with schema drift, sampled events, and cross-domain session failures. This blueprint is a hands-on walkthrough for building a semantic layer on Snowplow's behavioral data in Snowflake and wiring it up to a Snowflake CoWork agent, so your teams can query it in plain English and actually trust what comes back.

- Why schema-validated, enriched event data gives an agent something solid to reason over, and where typical clickstream data falls short
- A full setup walkthrough: semantic view creation, a ready-to-use YAML template, and Snowflake CoWork agent configuration
- A prompt library organized by use case (traffic analysis, funnel drop-off, anomaly detection) plus 5 example queries that only work because the underlying data is structured and validated

Grab the blueprint from Snowplow and see what a properly grounded data agent can actually do.

[Read the blueprint](https://insights.snowplow.io/l/1092822/2026-07-31/8mmyg8)

## Running Durable Agents in Production

Most agents run cleanly in a demo and then break the first time something goes wrong in production. The agent logic was never the hard part. Keeping it running reliably is.

In this workshop, Nicholas Lotz shows how to turn a working agent loop into a durable production workflow that can pause, recover, retry, and keep a full execution history.

You'll learn how to:

- Persist agent state outside the running process, so a crash doesn't lose progress
- Resume execution after crashes or interrupted deployments
- Retry flaky tool calls with timeouts and recovery logic
- Add human approval steps and more!

By the end, you'll understand the execution layer that separates a clever agent demo from a reliable agent service.
