On September 15, Louis Amaudruz, AI Engineer at Sandbox AQ, joined us for a hands-on workshop on multi-agent workflows. Louis walked us through Switch, an open-source framework that runs agents in messaging platforms like Slack, and built a small agent team live: a coder, a reviewer, and a lead that coordinates them.

## Podcast recording: Decoding the Open Lakehouse

On September 14, we talked with Sahil Walia, Senior Technical Architect at Snowflake, about how data platforms have changed, from writing simple SQL queries to running enterprise-scale Apache Iceberg lakehouses. We discussed:

- How Apache Iceberg differs from Hive metastores and compares to Delta Lake
- How Iceberg metadata helps with GDPR deletions and file compaction
- Whether you need a lakehouse for small data
- How to start contributing to open-source data projects
